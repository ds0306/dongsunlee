DONG SUN LEE — GITHUB PAGES HOMEPAGE

Files:
- index.html — main homepage
- CV-Dong Sun Lee.docx — downloadable CV
- .nojekyll — prevents unnecessary Jekyll processing

GitHub Pages setup:
1. Create a GitHub repository named USERNAME.github.io, replacing USERNAME with your GitHub username.
2. Set the repository to Public if you are using GitHub Free.
3. Upload index.html, CV-Dong Sun Lee.docx, and .nojekyll to the top level of the repository.
4. Go to Settings → Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select the main branch and the / (root) folder, then Save.
7. After publication, the site will be available at https://USERNAME.github.io/
